# CarBiz AutoMod V5.4 Studio UI

Frontend redesign based on the AI workshop / tuning-studio visual direction.

## What changed
- Full-screen vehicle-first studio layout
- Left modification panels with thumbnail cards
- Floating AI analysis banner
- Vertical right-side category tabs
- My Build / Smart Fitment HUD
- Centered Render / Before / After controls
- Cyan + orange tuning-studio visual language
- Keeps uploaded vehicle photo as the hero image
- Keeps existing V5.3 backend endpoints and Render service

## Deploy
Replace `index.html` and `README.md` in the existing GitHub repo.
You may upload the whole ZIP, but no backend change is required for the UI redesign.

Existing backend URL in `config.js` remains unchanged.
